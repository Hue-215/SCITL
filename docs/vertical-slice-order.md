# 縦切り完成までの着手順

マイルストーン「縦切り完成」に入っているIssueを、どの順で着手するかと、その理由を記録する。

**このファイルに書くのは、残っている作業の順序と理由だけ**。終えた段は消す(経緯は`git log`と
closed Issueで足りる)。各Issueが開いているか閉じているかはGitHub Issuesが正であり、ここには
書かない。順序の前提が変わったとき(依存が増えた・不要になった等)と、段を終えたときにだけ更新する。

並べ方の方針は次の3つ。

1. **後続の作り直しを生む土台を先に置く**(設定ファイルの形・履歴の作り方・イベント経路)
2. **安全側の穴を、その穴を広げる機能より先に塞ぐ**(描画のサニタイズ・自由入力の無害化)
3. 同じ層を触るIssueをまとめ、同じコンテキストで連続して片付ける
