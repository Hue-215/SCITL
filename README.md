# SCITL Task Companion

LLM APIを接続して使う、チャット風のタスク管理ソフトです。

![実際の画面](docs/images/screenshot.png)

## 特徴

SCITLはチャット機能を中心として開発されており、会話感覚でタスクの追加や進捗管理を行うことができます。
また、インストールや外部通信を必要としない設計としているため、ローカルLLMが載るPCであればオフライン状態でも使うことができます。

## 対応OS

開発作業はKubuntu 26.04 LTSで行っているので、同じものを用意してもらえればほぼ確実に動きます。
Windows対応も一応行っていますが、作者があまり使っていないためバグ等が残っている可能性があります。
Macは持っていないので対応しません。
Android(10以上、arm64)向けのAPKも置いています。

## つかいかた

Releasesからお好みのバージョンを落として展開し、あとは実行ファイルを実行してもらえれば動くはずです。会話データ等は実行ファイルと同じ場所に、APIキーなどはOSの資格情報ストアに保存されます。
LLM APIはOpenAI、Anthropic、Geminiに対応しているつもりですが、AnthropicはAPIが高いのであまり検証していません。OpenAIも互換鯖でしか試してないですが、こっちはガバガバなので大丈夫なはずです。
また、LinuxではWebKitGTK 4.1、WindowsではWebView2が必要です。

Androidは、Releasesの`.apk`を端末に落として開けば入ります。Google Playを通していないので、初回はダウンロードに使ったアプリ(ブラウザなど)に「提供元不明のアプリのインストール」を許可する必要があります。データはアプリの中に保存されるので、アンインストールすると一緒に消えます。

## CLI

PC上の他のエージェントなどにタスクの閲覧や整理(名前の変更・アーカイブ・削除)を行わせるためのCLIが同梱されています。よしなに使ってやってください。

## 開発者向け

このソフトのコーディングやドキュメント作成は現状Claudeが全部やっているので、バグや脆弱性、その他変な部分がいろいろ残っている可能性があります。不具合はIssue、脆弱性はGitHubに脆弱性を報告する機能があるのでそちらからこっそり教えて貰えると助かります。

また、もしSCITLを自分で改造してやるぜ！という変な気を起こした場合、このソフトはTauriで動いてるらしいのでTauri用の環境を用意してもらえれば色々弄れると思います。
