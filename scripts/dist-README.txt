SCITL Task Companion

チャットでタスクの内容や締切を聞き取り、進捗の報告もチャットで行うタスク管理ソフトです。
LLMのAPI(OpenAI互換・Anthropic・Gemini)を自分で登録して使います。

■ 入っているもの

  scitl                  本体(Windowsは scitl.exe)
  scitl-cli              タスクの一覧・詳細・名前の変更・アーカイブ・削除と、会話の表示を
                         コマンドラインから行うもの(Windowsは scitl-cli.exe)
  LICENSE                このソフトのライセンス(MIT)
  THIRD-PARTY-LICENSES   同梱しているライブラリとフォントのライセンス

■ 必要なもの

  Linux    WebKitGTK 4.1(Debian・Ubuntuは libwebkit2gtk-4.1-0、Fedoraは webkit2gtk4.1)と
           glibc 2.39以上。APIキーの保存にSecret Serviceを使います。
  Windows  WebView2。実行ファイルにコード署名が無いので、初回の起動で「WindowsによってPCが
           保護されました」という警告が出ることがあります。「詳細情報」→「実行」で起動できます。

■ 使い方

  1. このフォルダを、自分のユーザーフォルダの下に置きます。
  2. scitl を起動します。
  3. 設定画面でLLMのAPIを登録し、モデルを追加します。

■ データの置き場所

  ・会話・設定・添付は、このフォルダの中の data に置かれます。
    APIキーはOSの資格情報ストアに保存され、このフォルダには入りません。
  ・圧縮ファイルの中から直接起動すると、起動を断ります。展開してから起動してください。
  ・Windowsで C:\ の直下などに置くと、同じPCの他のアカウントから読み書きできます。
  ・このフォルダを、同時に2か所から開かないでください。同期するフォルダ(クラウドストレージ等)や
    ネットワークドライブにも置かないでください。データベースが壊れることがあります。
  ・新しい版に上げるときは、古いフォルダの data を新しいフォルダへ移してください。
    移さないと、空のデータで起動します。

■ 外部ツール(MCP)

  ・接続方式は streamable HTTP だけです。
  ・stdioで動くサーバーは、stdioをHTTPへ中継するツール(supergateway・mcp-proxy 等)を手元で
    起動し、そのURLを登録して使います。中継は 127.0.0.1 で待ち受けさせ、認証用のトークンを必須にして、
    その値をヘッダーとして登録してください。
